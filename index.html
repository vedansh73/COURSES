Security & Architecture Documentation

This single-page web application provides front-end course distribution.

Frontend Security Limitations

Because this is built entirely as a client-side Single HTML File without a server component, standard authentication mechanisms are limited. To minimize visibility of raw access keys:

  • The cleartext access key is hashed using SHA-256 algorithm.
  • No raw passwords or plain text check conditions are rendered into visible elements or client JS variables.
  • Production environments requiring enterprise security should replace client-side JS validation with an authenticated API backend (e.g., Firebase Auth, Node.js/Express backend API).
